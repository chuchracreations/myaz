Everything below lives one command away

Eight modules, each doing one job well — reachable from the sidebar or the Command Palette (⌘⇧P / Ctrl⇧P).

Snippets

Save, search and insert reusable code with live syntax highlighting.

myaz.snippets.insert

  • Highlighting for TS, Python, SQL, Bash & more
  • Native tab-stops — $1, ${1:name}
  • Favorites, tags, and instant search

Converters

Documents, images, spreadsheets and data formats — batch-converted offline.

myaz.convertFile

  • SVG → multi-res icon pack (16px–512px ZIP)
  • Markdown → interactive slide deck
  • PDF → structured Markdown extraction

Ports

Find and kill blocked dev server ports without touching the terminal.

myaz.scanPorts

  • Flags ghost processes started in this workspace
  • Monorepo & microservice aware
  • Kill one, or Kill All, or restart on a port

Utilities

Nine tabs you'd normally have open, built in.

JWTUUIDBase64 SHA-256URLDate/TZRegex CronCase

Random Data

20 fake-data generators plus a batch mode, for demos and seed scripts.

  • Names, emails, addresses, passwords & more
  • IPs use the safe RFC 5737 range
  • Nothing generated ever resembles a real record

Vim Guide

128 Vim commands, searchable and organized into 13 categories.

  • Modes, movement, editing, registers, macros & more
  • Search or filter by category
  • Click any command to copy it

Git Cheat Sheet

74 everyday git commands, from staging to rebasing to stashing.

  • Branching, remotes, undoing changes, tags & more
  • Search or filter by category
  • Click any command to copy it

JSON Formatter

Format, minify, validate, and explore JSON as a collapsible tree.

  • Errors point to the exact line & column
  • Expand/collapse-all tree controls
  • Live key count, depth & size stats

Why local matters

Your code never leaves the editor

Every one of myaz's eight modules runs as plain JavaScript in the extension host — there is no server, no API key, and no network call to fail, log, or leak.

Quick start

Running in under a minute

  1. 1

    Install

    Search myaz in the Extensions view, or run:

    ext install himanshuchuchra.myaz-extension
  2. 2

    Open

    Click the myaz icon in the Activity Bar — the blue-violet "M".

  3. 3

    Pick a module

    Nothing to configure, nothing to sign into. It's already local.
